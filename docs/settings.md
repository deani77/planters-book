# Settings on Android and iOS

Both interfaces expose User Profile, Appearance, Inbox, Suggestions, and Estate Data Management.

Profile fields (display name, position, phone) and appearance choices are saved on the device. The profile is not a signed-in identity. Inbox and Suggestions remain local placeholders.

Estate Data Management lets users save an estate name, download a blank Excel template, import a completed XLSX or JSON file, and review changes before saving. Imports run on-device and work offline. The current and previous estate snapshots are retained locally.

See local data updates in data-updates.md for the workbook sheets, supported fields, size limits, and replacement behavior.
