# Soil suitability reference

The Soil Type panel reads area, share and agricultural suitability Class I–V from the private synced soil table. No estate records are bundled in the app.

Reference: I. F. T. Wong, Reconnaissance Soil Survey of Selangor, Ministry of Agriculture and Lands, October 1970, pp. 9–10, Table 3. https://www.wossac.com/downloads/WOSSAC_1667.pdf

Table 3 lists Bungor and Durian under Class III, and Tavy under Class II. Page 9 explains that terrain, drainage and effective rooting depth can alter suitability. These are historical reference ratings from Selangor, not verified ratings for another estate or an oil-palm-specific assessment. The app labels them as reference classes with estate verification pending. Do not infer class hectares from these reference ratings.

The private soil table may add Suitability class (I–V), Class reference and Class qualification columns; other categories such as Terrain retain null cells. Missing or unreferenced ratings display Pending. Soil series hectares must reconcile with current field hectares and shares before the panel displays them. Updates are retained in offline storage.
