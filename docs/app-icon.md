# App icon

The launcher icon uses the approved enlarged cream S3 lettering with one oil palm tree behind it on a forest green background. Artwork was generated with OpenAI Imagegen and resized to a 192 × 192 PNG for launcher use.

The app supports Android 8.0 (API 26) and later, so both icon and roundIcon use an adaptive icon. The artwork has an inset to keep lettering inside common circular and rounded-square launcher masks. No estate data is included.

Check the launcher after installing the updated APK on a device. An existing installation may require a launcher refresh before showing the new icon. A separate monochrome themed icon is not provided.
